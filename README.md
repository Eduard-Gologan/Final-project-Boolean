# Final-project-Boolean
From the endo of June until the end of July , we were split in different groups and we had to analyze an e-commerce activity. 
 This project allowed us to analyze different trends of the customers, know the products which we can apply for particular discount, bundles or promotions, the countries where people buy mostly, the age and gender of the customer, orders situations done during the years and the stock, Revenue and sales by category.
 As instruments we used a dataset form google bigquery "bigquery-public-data.thelook_ecommerce" and then Python for Cleaning and order the dataset from NaN values and duplicates, order their indexes and import them on tableau to make our data visualization.
  We imported the graphics on Powerpoint with some explanations to allow the users to understand our analysis.
